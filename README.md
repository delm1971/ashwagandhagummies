# Goli affiliate landing page

Extract this ZIP, then upload index.html, the assets folder, and .nojekyll to the root of your GitHub repository. Upload the extracted files, not the ZIP.

Enable GitHub Pages in Settings > Pages, choose Deploy from a branch, then main and / (root), and save.

Keep the assets folder beside index.html so all four images load. Open index.html locally to preview. All shopping buttons retain the supplied affiliate URL and discount code.
